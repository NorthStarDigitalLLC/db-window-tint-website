# DB Window Tint & Car Audio

Complete standalone website for the Anderson, South Carolina shop. All site files, six vehicle photos, and fonts are included.

## Set up your own copy

[**Set up with GitHub + Vercel**](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FNorthStarDigitalLLC%2Fdb-window-tint-website)

1. Create your own [GitHub account](https://github.com/signup). Create a [Vercel account](https://vercel.com/signup) using GitHub.
2. Use the setup link above. Select **GitHub** as the repository provider and your own account as its owner. Allow Vercel to create/access the new repository when prompted.
3. Name the repository `db-window-tint-website`, choose the Vercel team you want to own the site, and finish **Create / Deploy**. Vercel copies this repository into your GitHub account and deploys it.
4. Open the resulting `.vercel.app` address. In Vercel, use **Project Settings → Domains** to connect a domain you own.

For this business website, use a Vercel plan that permits commercial use, such as Pro. [Vercel Hobby is for personal, non-commercial use](https://vercel.com/docs/plans/hobby). Hosting and domain subscriptions belong to your own accounts; creating this template does not purchase either.

The supplied `vercel.json` configures a plain static website: Framework **Other**, project root **./**, output directory **.**, and no install or build command. No environment variables or API keys are needed.

If you prefer to create the GitHub repository first, select **Use this template → Create a new repository**, choose your own account, and then import that repository at [vercel.com/new](https://vercel.com/new). Use one route or the other, not both.

## Future changes

Edit files in your own GitHub repository and commit to `main`. With the Vercel Git integration connected, each push to the production branch publishes an updated site. Keep any older version in Git history if you need to restore it.

- `index.html`: wording, contact information, hours, and page structure.
- `styles.css`: colors, design, and responsive layouts.
- `app.js`: gallery, vehicle selector, and message planner.
- `assets/`: photos, fonts, and font licenses.

You can edit a file in GitHub with its pencil button, then choose **Commit changes**. The site has no separate visual editing dashboard. Downloading the repository also gives you ordinary HTML/CSS/JavaScript files that can run on another static host.

## What works

- Desktop and mobile layouts, gallery filters, photo viewer, and hero vehicle selector.
- Phone and map links.
- A project planner that prepares a message for the visitor to review, copy, or open in their texting app.

The visitor chooses whether to send the text. This site does not book appointments, take payments, receive messages on a server, or store customer submissions.
